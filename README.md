# supply_chains_and_sales_data_warehouse_and_BI_project
This project focused on designing a complete Business Intelligence (BI) solution using SQL server Analysis Services (SSAS) and Power BI to transform raw  supply chain and sales transactional data into meaningful business insights.


## This project includes:
-Designed an Supply chain and sales warehouse using star schema.
-Developed an OLAP Cube with SQL Server Analysis services (SSAS).
-Create multi-dimensional hierarchies for Date and Product dimensions.
-Demostrated key OLAP operations including Roll-Up, Drill-Down, Slice, Dice and Pivot.
-Built Interactive Power BI dashboards with Cascading slicers, Drill-through reports and Matrix visualizations.
-Published reports to Power BI Service for interactive business reporting.


## technologies Used:
-Microsoft SQL Server
-SQL Server Analysis Services (SSAS)
-SQL Server Data Tools (SSDT)
-Power BI Desktop
-Power BI Service
-Microsoft Excel
